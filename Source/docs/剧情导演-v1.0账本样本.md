## 3. 迁移必须满足（R-K3 验收点）

用上面这份快照喂给**升级后**的解析层，要求：

- ☐ **不崩**：解析不抛错（`Schema.parse` / 手写解析都不崩）
- ☐ **不清空**：3 条伏笔、1 条冲突、1 条弧线、章回全部**原样保留**
- ☐ **默认填充**：新增字段（`指标.*`、`已剧终` …）补默认值，不 undefined
- ☐ **`伏笔.埋设章` 回填**：老条目缺该字段 → 回填为**当前章号**（本例 = 1），不是 0/undefined
- ☐ **`回收窗口` 兼容**：确认它是章号锚定字符串（"第1章收束前" / "第2章内"）——收束调度的正则要能吃下**两种**写法（"第N章收束前" 与 "第N章内"）
- ☐ **`当前指令: null` 合法**：冷启动期没有指令是正常态，不能被判成损坏
- ☐ **`张力.最近节拍: ["阴影"]`**：节拍枚举里含"阴影"，解析要认（冷启动第 1 轮就有节拍值）
- ☐ **写入后再读回一致**：迁移后的快照写回楼层，再读出来与预期一致（往返一致）

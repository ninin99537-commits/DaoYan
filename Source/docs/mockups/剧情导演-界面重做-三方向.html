剧情导演 · 界面重做 —— 三个方向（第一步 · 静态稿）

这一稿的重点不是配色，而是控件层：滑块 / 开关 / 下拉 / 披露 / 滚动条 / 选区与焦点环全部自绘，一个原生外观都不留。

可以动手试：拖动滑块 点开关 开下拉(↑↓/Esc/点外关) 展开披露 切页签 Tab 走一圈看焦点环 hover 悬浮球看气泡

尺寸按真机契约做的：面板 460×620（名义上限），球 40×40（此处放大 1.6× 便于看材质）。三稿都守「暖墨 + 唯一朱红 + 2px 圆角」，差异在材质、密度、字体与控件形态。

悬浮球标是画出来的标记（自绘 SVG · 单色描边 1.6px · 40×40 与面板内小尺寸都可辨）：没有汉字、没有 emoji。球标只承担身份，五态由环/色/动效表达 —— 四个方案见下方 ④。

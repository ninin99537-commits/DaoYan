## 1. H 接口健康检查

- ☐ `api.ts` 前置校验**密钥非空**，错误可分类（密钥未配置 / 地址未配置 / 模型未选择）
- ☐ `updateDirector` 校验扩为**地址/密钥/模型三空**（R0 不止密钥空）
- ☐ 设置页接口区**标红**提示缺失项
- ☐ **「测试连接」按钮存在**：发一次短 chatCompletion，并把错误分类显示
- ☐ **探测 `max_token`（R1 已实测不成立）**：「测试连接」能识别三类失败——① 401（密钥错）② 400/参数错（含 max_tokens 超限）③ **正文空 + completion_tokens 用满 = 推理吃满预算 → 提示调大**（不是接口错）
- ☐ 密钥空（或三空）时**拦截自动推进**——不发请求、不静默 401
- ☐ **引擎默认最大 token 保持 60000**——⚠️ **不得改小到 4096**（用户模型 deepseek-flash 是**推理模型**，小预算会被推理吃光、正文返回空；dsh 2026-10-07 00:30 实测 60000 通过、32 空正文）。若为兼容别端点做回退，回退值 **≥16384**
- ☐ 用例钉住：三空校验 / 测试连接的错误分类（含第③类）

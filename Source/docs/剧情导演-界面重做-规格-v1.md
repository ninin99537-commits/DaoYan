---

## 0. 失败根因（审计实据，2026-10-07）

风格 B 只动了**设计令牌**（颜色/字体/圆角/阴影），**表单控件仍是浏览器默认**：

| 控件 | 现状（`悬浮球界面.vue`，979 行） | 判定 |
| --- | --- | --- |
| 强度滑动条 | `<input type="range">` ×1；**无** `appearance` / `::-webkit-slider-runnable-track` / `::-webkit-slider-thumb` / `::-moz-range-*` / `accent-color` | ❌ **全原生** |
| 勾选 | `<input type="checkbox">` ×**11**；**零** `appearance: none` | ❌ **全原生** |
| 下拉 | `<select>` ×4 + `<option>` ×5；无自定义 | ❌ 原生 |
| 折叠 | `<details>/<summary>` ×5；无自定义（原生三角） | ❌ 原生 |
| 滚动 | `overflow:auto` ×2；`::-webkit-scrollbar`/`scrollbar-width` **均无** | ❌ 原生滚动条 |
| 选区 | `::selection` 无 | ❌ 默认 |

→ **结论**：重做必须**自建控件层**，而不是再调一遍颜色。

---

## 1. 硬指标（这次验收要逐条打勾，做不到就是没做完）

### 1.1 零原生控件
1. **滑动条**：`appearance: none` + 自绘轨道/已填充段/滑块；支持键盘（←→/Home/End）、`disabled`、`focus-visible` 环；档位刻度可显示（1–4 档）。
2. **勾选**：改为**自绘开关（switch）或自绘勾选块**，`appearance: none`；保留原生 `<input type="checkbox">` 语义（或 `role="switch"` + `aria-checked`），键盘可切（Space）。
3. **下拉**：改为**自绘下拉**（按钮 + 浮层列表，`aria-haspopup="listbox"`/`aria-expanded`，↑↓ 选择、Esc 关闭、点外关闭）；**不得**直接裸露 `<select>` 默认外观（若保留 `<select>`，必须 `appearance:none` 且自绘箭头与浮层样式）。
4. **折叠**：弃用 `<details>/<summary>` 的原生三角，改为**自绘披露**（自绘箭头 + 展开/收起动效 + `aria-expanded`）。
5. **滚动条**：面板内所有滚动区自绘（`scrollbar-width: thin` + `scrollbar-color`，并补 `::-webkit-scrollbar/-thumb/-track`）。
6. **选区/聚焦**：`::selection` 用主题色；全局 `:focus-visible` 统一光环（不许浏览器默认蓝框）。

### 1.2 视觉与结构（"不丑"的最低门槛）
7. **层级**：标题/分组/正文/说明四级必须**视觉可区分**（字号/字重/颜色/间距至少三个维度同时变化，不许只改字号）。
8. **间距**：统一 4px 基准栅格（4/8/12/16/24）；同类元素间距一致，**不许手写零散 px**。
9. **圆角/描边/阴影**：沿用风格 B 的 2px 圆角与暖墨体系；阴影只用 `inset` 或极浅投影，**不许"糊一层灰"**。
10. **强调色克制**：全屏朱红**只用于 1 处主操作 + 状态点**，其余用中性阶。
11. **数字与等宽**：所有读数/指标 `font-variant-numeric: tabular-nums`。
12. **动效**：120–180ms，只做"有意义"的（展开/切换/状态变化）；`prefers-reduced-motion` 全部降级为无动效。

### 1.3 悬浮球（用户点名"包括悬浮球"）
13. **球体重做**：不是"圆 + emoji/字"；要有**材质感**（内阴影/高光/边缘光至少两项）+ **五态可辨**（剧终/离线/出错/编排中/待命，颜色+形态+动效各不同）。
14. **编排中**要有**可读的进行感**（呼吸/扫光/环进度），但不许用原生 `<progress>`、不许用 GIF。
15. **悬停/聚焦**要有**信息层**（球旁气泡：当前态 + 最近一次编排的节拍与时间），且不遮挡聊天。
16. **拖拽/吸附**保留既有行为，拖拽时球体有抓取反馈。

### 1.4 不可动的红线（沿用既有契约）
17. **零截断**：显示层折叠合法；**禁止**用 `overflow:hidden` 裁正文；发送路径禁止 `.slice()`。
18. **面板尺寸契约**：名义上限 460×620；`computePanelSize()` 逻辑不变；`applyFrame()` 的"球∪面板并集+4px"不变。
19. **类名契约**：现有 34 个 `dj-*` 关键类名与 14 个 DOM 契约类**保留**（新增控件类以 `dj-ctl*` 前缀命名）；如需改名，必须在规格里列出对照表。
20. **令牌来源唯一**：所有颜色/字号/间距来自 `主题.ts`；**不许硬编码颜色**（新增控件令牌：轨道/滑块/开关关-开/浮层/焦点环）。
21. **零全局污染**：样式只写在 `.vue` 的 `scoped` 块 + `主题.ts`；不得影响酒馆其它插件。

### 1.5 测试与门槛（复用既有纪律）
22. `pnpm test` 全绿（现有 40 用例不许放宽）；新增用例至少覆盖：
    滑动条自绘（`appearance:none`、`::-webkit-slider-thumb` 存在）、勾选自绘、下拉自绘、折叠自绘、滚动条自绘、**无原生 `<summary>` 三角依赖**；
    仍保持：`vh` 0 处、`position:absolute` 不新增（除既有 tab 下划线）、硬编码色 0 处。
23. `@vue/compiler-sfc` 真编译零错（parse/template/scss 三关）。

### 1.3bis 悬浮球**球标**（用户 2026-10-07 14:4x 追加要求）

> 用户原话：「**悬浮球不要一个导演的导字，也要有设计感**」

**现状**：稿里球体是 `<span class="glyph">导</span>`（五个状态各一处）⇒ **不合格**。

**硬指标**：
24. **禁止**用任何汉字作球标（不许 `导`/`剧`/`演`/`戏`…），也禁止用 emoji 当球标。
25. 球标必须是**画出来的标记**（内联 SVG 或纯 CSS 图形），**单色**（`currentColor`），**描边风**（1.5–1.7px），
    **在 40×40 与面板内小尺寸下都可辨**。
26. 球标承担**身份**，**不承担状态**——五态由环/色/动效表达，球标在五态中**保持不变**（否则用户认不出是同一个东西）。
27. **至少给 3 个球标方案**（可跨方向复用），每个附一句隐喻说明，供用户挑。**建议候选**（不限于）：
    - **场记板**（抽象成"顶杆 + 斜纹"两三笔）——最直白的"导演"隐喻；
    - **三幕张力弧**（一条起-峰-落的曲线）——直接对应本插件干的事（张力波形），最贴功能；
    - **取景框/光圈**（方框 + 内圈缺口）——"镜头/视角"隐喻；
    - **场次刻度**（三根不同高度的短线）——极简、在小尺寸最稳。
28. 球标需可动：`编排中` 时允许**沿环走/描线/呼吸**（`prefers-reduced-motion` 下静止）。

### 1.1bis 文本/数字输入框（用户 2026-10-07 15:1x 追加 —— dsh 审计漏项）

> 用户原话：「**接口的地址、密钥居然还是原生的，都还是白的**」

**实机证据**（设置页 13 个 input，10 个是 UA 默认）：地址 `text` 与密钥 `password`、8 个 `number`
（最大token/温度/读取最近回复数/接管轮数/快照保留份数/连续低阈值/连续高阈值…）实测
**背景 `rgb(255,255,255)` 纯白 · 描边 `1.6px rgb(118,118,118)`(UA 灰) · 字色 `rgb(0,0,0)` 纯黑 · 高 21.2px**；
只有 3 个（模型等）在 `.dj-field` 里被正确上了主题令牌（背景 `oklch(0.17 0.008 60)`、字色亮墨、高 28.2px）。

**硬指标（新增）**：
29. **所有** `input`（`text`/`password`/`number`/`search`/`url`/`email`/无 type）与 `textarea` 一律主题化：
    背景/描边/圆角/字色/字号/高度/内距 全部走令牌；`appearance:none`；**去掉 number 的原生转轮**；`::placeholder` 用弱墨；`:focus-visible` 统一光环；`:disabled` 降透明。
30. **判据是实测 computed style，不是"代码里写了没有"**：面板里**不得存在**背景为 `rgb(255,255,255)` 或描边为 UA 灰 `rgb(118,118,118)` 的输入类元素。
31. **必须逐个列出**面板内全部表单元素及其覆盖情况（地址/密钥/模型/最大token/温度/… 一个不落），作为交付证据。

### 1.3ter 悬浮球气泡必须**跟随球**（用户 2026-10-07 15:1x 追加）

> 用户原话：「**鼠标放到悬浮球上不是有个弹窗嘛，那个弹窗居然是固定在一个地方的**」

**实机证据**：
- `#dj-orb-tip`：`position:fixed; left:1660px; top:739px`（固定），与球无关；
- `#dj-toast-anchor`（气泡定位依赖的"球心锚点"）：**`display:none`、`w=0 h=0`** ⇒ `球气泡.ts:锚点坐标()` 取不到值 → 走**兜底：右下角固定位置**。

**根因**：该锚点是 **toast 系统**的（只在弹 toast 时更新）；球**未被拖动过**时从未赋值 ⇒ 气泡永远钉在一处。

**硬指标（新增）**：
32. **气泡位置必须由球的实时位置算出**（父页面里球 iframe 的 `getBoundingClientRect()` + 球在 iframe 内的偏移），
    **不得依赖 toast 锚点**（或必须在使用前**主动刷新**该锚点）；
33. 球**被拖动**时气泡跟随（或至少下次悬停时用新坐标）；
34. 靠近视口边缘时**翻到另一侧**（现有翻转逻辑保留）且不越界；
35. 窗口 resize / 页面滚动后，下一次显示用新坐标（不做脏缓存）。
